# JobScout for macOS and iOS

JobScout is a personal job-search app with native SwiftUI clients and a Python backend. It collects vacancies from configured feeds, optional browser collectors, and saved imports, scores them against your preferences, and tracks application statuses. Both clients support searching, filtering, vacancy details, and offline reading; the Mac hosts the service and stores vacancies, settings, and reports locally.

Open `JobScout.xcodeproj` and run **JobScout** on macOS 15+ or **JobScoutIOS** on iOS 18+. The Mac backend requires Python 3.12+; browser collection additionally requires Playwright and Chromium. Local data lives in `~/Library/Application Support/JobScout/` and survives rebuilds. For setup, commands, and source limitations, see the [backend guide](Backend/README.md); for iPhone connections and service configuration, see the [API guide](Backend/API.md). The [architecture guide](Docs/Architecture.md) explains the shared Swift package and application structure.
